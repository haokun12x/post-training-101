One gradient behind every method.一个梯度，统一所有方法

μ fixedμ 固定

05Part 3 · Offline vs. online第三部分 · 离线与在线

Fixed data is a trainer. Fresh data is a loop.固定数据是训练器，实时数据是闭环

3.1

Offline: SFT & DPO离线：SFT 与 DPO

No generation engine needed; πref log-probs can be precomputed. Recipes: LLaMA-Factory · ms-swift · Axolotl. Memory/speed: Unsloth. JAX/TPU: Tunix.不需要生成引擎；πref 的对数概率可预先计算。配方：LLaMA-Factory · ms-swift · Axolotl；省显存提速：Unsloth；JAX/TPU：Tunix。

The normalizer is part of the objective归一化因子是目标函数的一部分

Example: G = 2, |y₁| = 100, |y₂| = 1000. Sequence-mean gives 1/200 vs 1/2000 per token (10× apart); token-mean gives 1/1100 to every token. A mean of micro-batch means ≠ the global mean.例：G = 2，|y₁| = 100，|y₂| = 1000。序列平均下每个 token 的权重是 1/200 对 1/2000（相差 10 倍）；token 平均下每个 token 都是 1/1100。微批均值的均值 ≠ 全局均值。

Code-review finding (TRL @72cf37d): a custom compute_loss_func triggers a full-logits forward plus an extra no-grad fused forward for metrics, while the default uses the fused LM head. Changing the loss can change memory and throughput.源码审查发现（TRL @72cf37d）：自定义 compute_loss_func 会走完整 logits 前向，并为指标额外做一次 no-grad 融合前向；默认路径使用融合 LM head。改 loss 可能改变显存与吞吐。

Online: the loop and its objectives在线：闭环与目标函数

06Part 4 · Where systems really differ第四部分 · 系统真正的差异

Not the algorithm list. Everything around it.差距不在算法列表，而在它周围的一切

Scheduling, train–inference consistency, MoE depth, weight transfer and recovery decide the outcome. Find the bottleneck first.调度、训练推理一致性、MoE 深度、权重传输与恢复能力决定结果。先找到瓶颈。

4.1

Step time: published numbers单步时间：官方公布的数字

Official numbers are per-step (≈ 5-step averages) or per-phase, not convergence speed and not end-to-end speedups. Amdahl check: generation 80%, training 20%, train 2× faster → 0.8 + 0.2/2 = 0.90, only 10% saved. Optimize cost-to-target = Σ GPUs × hours per role until the validation target is reached.官方数字是单步（约 5 步平均）或单阶段的，不代表收敛速度，也不是端到端加速。Amdahl 检验：生成 80%、训练 20%，训练加速 2 倍 → 0.8 + 0.2/2 = 0.90，只节省 10%。要优化的是达标成本 = 各角色 GPU 数 × 小时数之和（直到验证集达标）。

4.2

Asynchrony is not a boolean异步不是一个布尔开关

⚠ The same “staleness = 2” is not the same age across frameworks, and dropping slow trajectories quietly removes the hard problems. Version belongs to token spans: a mid-flight update produces one trajectory from two policies.⚠ 不同框架里同样的 “staleness = 2” 并不代表同样的版本年龄；丢弃慢轨迹会悄悄移除难题。版本应绑定到 token 片段：生成中途更新权重，会让一条轨迹来自两个策略。

4.3

Train–inference consistency: five error sources训练—推理一致性：五个误差来源

A full-softmax recompute is off by the factor Z(S), differently for every token. Fix: normalize on the same candidate set during training (sampler-support replay).用完整 softmax 重算，会差一个 Z(S) 因子，而且每个 token 都不同。解决：训练时在同一候选集上归一化（采样支持集重放）。
